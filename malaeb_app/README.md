# ملاعب — نسخة تشغيل تجريبية

تحتوي هذه النسخة على واجهة العملاء، تسجيل أصحاب الملاعب، قاعدة بيانات SQLite، استقبال طلبات الحجز، ولوحة لصاحب الملعب لإدارة بياناته والرد على الطلبات.

## التشغيل

يتطلب Python 3.9 أو أحدث ولا يحتاج مكتبات خارجية.

1. افتح Terminal داخل مجلد `malaeb_app`.
2. شغّل `./run.sh` أو `python3 server.py`.
3. افتح `http://127.0.0.1:8000`.
4. سجّل ملعباً تجريبياً من رابط «لأصحاب الملاعب»؛ سيظهر بعدها للزبائن في صفحة اكتشاف الملاعب.

تُنشأ قاعدة البيانات `malaeb.sqlite3` بجانب التطبيق. احتفظ بنسخة احتياطية منها دورياً.

## ما يعمل الآن

- حساب مالك الملعب بكلمة مرور مخزنة بتجزئة PBKDF2 وجلسة دخول عبر Cookie.
- إنشاء وتعديل بيانات الملعب، المدينة والمنطقة والعنوان والسعر والأنواع.
- عرض الملاعب المسجلة للعملاء وإرسال طلب الحجز إلى قاعدة البيانات المشتركة.
- مشاهدة طلبات الحجز وتأكيدها أو رفضها من لوحة المالك.
- إنشاء طلب اهتمام باشتراك شهري/سنوي بحالة `pending`.

## قبل إطلاق عام أو تقاضي مبالغ

هذا نموذج MVP يعمل على جهاز واحد عند تشغيله محلياً. ليس مستضافاً على الإنترنت، ولا يرسل رسائل SMS أو WhatsApp أو بريد. الاشتراك يسجل اهتماماً فقط؛ لا توجد بوابة دفع أو تحصيل أموال، والأسعار المعروضة مقترحة. لا تضع بيانات دفع أو مفاتيح سرية في الواجهة.

للنشر الفعلي تحتاج استضافة HTTPS، نطاقاً، نسخاً احتياطية ومراقبة، ومراجعة أمنية، وسياسة خصوصية وشروط استخدام. يلزم أيضاً التعاقد وفتح حساب تاجر مع بوابة تدعم بلدك، ثم ربط واجهة الدفع والتحقق من إشعارات الدفع من الخادم قبل تفعيل الاشتراك. لا تفعّل اشتراكاً بناءً على صورة تحويل فقط.

قاعدة البيانات المحلية وملفات التطبيق لا تتضمن حسابات حقيقية حالياً.

### مراجعة اشتراكات التحويل اليدوي (اختياري)

على جهاز الخادم، اعرض الطلبات عبر `python3 admin.py pending`. بعد مطابقة التحويل فعلياً مع كشف الحساب، فعّل المرجع الصحيح بواسطة `python3 admin.py activate MLB-...`. هذا إجراء إداري يدوي للتجربة فقط؛ لا يعالج البطاقات أو المحافظ ولا يثبت وصول الأموال آلياً.

عند النشر خلف HTTPS، اضبط `MALAEb_SECURE_COOKIE=1` وشغّل الخدمة خلف خادم ويب إنتاجي آمن. لا تعرض منفذ خادم التطوير مباشرة للإنترنت.

ملف [STORE_RELEASE_CHECKLIST.md](STORE_RELEASE_CHECKLIST.md) يوضح إعداد الخادم العام، حماية البيانات، المتطلبات الناقصة للدفع والمتاجر، وما هو متوفر في هذه الحزمة. ملفات PWA تجعلها قابلة للإضافة إلى شاشة الهاتف من متصفح يدعم التثبيت، لكنها لا تعني أن التطبيق منشور في App Store أو Google Play.
